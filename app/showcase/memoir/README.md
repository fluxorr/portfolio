# Memoir showcase

Run `bun install` and `bun run dev:next` from the portfolio, then open `/showcase/memoir`. `bun run lint` and `bun run build` validate the portable Next.js deployment.

- The hero, Memory Room, use cases, and Ask Memoir share the fictional data in `lib/memoir.ts`. Ask resolves the example prompts locally and does not transmit questions. Sign-in and live source integrations are outside the sample workspace.
- To enable early-access signup, configure the server-only `MEMOIR_WAITLIST_ENDPOINT` and optional `MEMOIR_WAITLIST_TOKEN` before building. The endpoint receives a JSON POST with `email` and `source`, plus a stable `Idempotency-Key` header. It must persist or upsert by email, return 2xx after recording a submission, and reserve 409 for an already-recorded email. The route rejects redirects and times out after eight seconds. Without an endpoint, the page shows preview access and the endpoint returns 503.

The console uses StageShow’s hairline window composition, reworked around live controls. The hero’s original WebGL trace follows the ordered-dot and pointer-response ideas in [Magic UI Dither Field](https://magicui.design/docs/components/dither-field) and [React Bits ASCII Text](https://reactbits.dev/text-animations/ascii-text). The browser renders a still when WebGL is unavailable and stops drawing once the pointer settles. Links draw along their actual SVG path, following [Magic UI’s Animated Beam](https://magicui.design/docs/components/animated-beam). The Ask composer references [Nexvyn’s AI Input](https://ui.nexvyn.dev/components/ai-input), and the use-case layout takes its expansion cue from [Skiper UI](https://www.skiper-ui.com/v1/skiper23). The implementations use React, Motion, CSS/SVG, and the same Radix primitives used by shadcn’s Radix components. No library previews or paid source files are bundled.
